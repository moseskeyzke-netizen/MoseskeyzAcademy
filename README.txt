MOSES KEYZ PIANO ACADEMY – VERSION 2

Audience: Beginners
Brand: Moses Keyz Piano Academy
Planned monetization: advertising + premium lessons

Included:
- Beginner-friendly home/lesson screen
- Major chord lesson
- 12-key chord selector
- Gospel progression guide
- Interactive practice quiz
- Academy tab explaining free learning, future premium lessons and future ad placement

Important:
This is a working front-end learning prototype. It does NOT yet contain live advertising, payment processing, user accounts, cloud progress saving, or a published Android package. No earnings are active.

Test locally:
Open index.html in a modern browser.

Publish as a website:
Upload the files to a static HTTPS host such as GitHub Pages. The app manifest and service worker allow installation/offline caching when served over HTTPS.

Android:
After hosting, open the website in Chrome on Android and use the browser menu's Install app / Add to Home screen option. A Play Store release is a separate later step and may require a developer account and compliance work.
